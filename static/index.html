▸ HUNT THE RING

Mule networks reuse infrastructure. The agent finds 4+ accounts sharing one device, then pulls the IPs they share — the classic fraud-ring fingerprint, as a single graph pattern.

▸ FIND THE HUB

Laundering hubs sit at the center of mule networks. The agent runs PageRank over TRANSFERRED edges — the highest-scoring accounts are the network's kingpins, found with zero labels.

▸ EXECUTE FREEZE — THE AGENT ACTS

Reading the graph was reconnaissance. This is the action. The agent freezes every staged account (frozen=true) and writes a (:Case)-[:TARGETS]->(:Account) case file into the graph — memory the next investigation can build on. This write is the only mutation the API allows.
